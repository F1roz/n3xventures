# N3X Ventures website

Static site for https://n3xventures.vercel.app — deploy this folder to Vercel as-is (no build step).

All internal links are relative `.html` paths, so the site also works locally in VS Code Live Server or by opening `index.html` directly. On Vercel, `cleanUrls` serves them as clean URLs (e.g. `/services/seo-geo`).

## Structure
- `index.html`, `about.html`, `coaches.html`, `contact.html`, `privacy.html`, `terms.html`, `404.html`
- `services/` — services hub + 10 service pages
- `industries/` — industries hub · `niches/` — 23 industry pages (original URLs kept)
- `blog/` — blog index, 12 articles (one page each), `feed.xml`
- `assets/css/n3x.css`, `assets/js/n3x.js`, `assets/img/` (photos, webp), `assets/brand/` (logos, favicons, OG image)
- SEO / GEO / AEO: `sitemap.xml`, `robots.txt` (AI crawlers allowed), `llms.txt`, JSON-LD schema on every page
- Google tag G-T8WX7GJDET sits immediately after `<head>` on every page (exactly once).

## Booking & forms
`assets/js/n3x.js` holds `CALENDLY_URL` and `FORMSPREE_URL`. Any element with `data-book` opens the booking modal.

## Editing / adding blog posts (optional)
Pages are generated by `_build/` (ignored by Vercel). To regenerate after editing content:
```
cd _build && npm install && N3X_OUT=.. python3 build.py
```
Add a post by appending to `posts2.py` (same fields as existing posts). If you edit CSS/JS, bump `?v=2` in `layout.py` (assets are cached for a year).
